# 地点探索与打卡分享平台

一个基于地图的地点探索与内容分享项目，支持地点浏览、打卡分享、回复互动、推荐内容、活动发布以及运营后台管理。

这个项目当前更适合被理解为：

- 地点探索平台
- 打卡分享社区
- 地图内容运营后台练手项目

而不是“智慧校园综合系统”。

## 项目定位

核心能力围绕三条主线展开：

- 地图与地点探索：在地图中浏览地点、查看详情、规划路线
- 内容互动：发布地点打卡、回复、点赞、举报
- 运营治理：公告、活动、推荐、审核、日志、资源、配置

这套结构天然可以继续扩展到：

- 校园场景
- 城市景点
- 商圈与美食地点
- 本地探索路线

## 项目结构

smart-campus-frontend/   Vue 3 + Vite + Element Plus 前端
smart-campus-backend/    Spring Boot 后端

## 本地运行

### 前端

```bash
cd smart-campus-frontend
npm install
npm run dev
```

### 后端

```bash
cd smart-campus-backend
./mvnw spring-boot:run
```

Windows 下也可以使用：

```bash
mvnw.cmd spring-boot:run
```
