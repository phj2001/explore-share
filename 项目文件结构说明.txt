  🔄 请求流程

  前端请求
      ↓
  JwtAuthenticationFilter (验证token)
      ↓
  Controller (接收请求)
      ↓
  Service (业务逻辑)
      ↓
  Repository (数据访问)
      ↓
  数据库
      ↓
  返回数据
      ↓
  GlobalExceptionHandler (异常处理)
      ↓
  统一响应格式 Result<T>
      ↓
  前端接收

整体开发步骤
我要从零重做一个校园地图管理系统。
技术栈：
- 前端：Vue3 + Vite + Element Plus + Pinia + Vue Router + Axios + Leaflet
- 后端：Spring Boot + Spring Data JPA + Spring Security + JWT
- 数据库：PostgreSQL + PostGIS

请按下面顺序帮助我，不要跳步，不要一次性把所有代码写完：

第一阶段：
1. 梳理业务目标
2. 梳理业务对象
3. 设计数据库表
4. 设计接口清单
5. 设计前后端目录结构

第二阶段：
1. 指导我创建后端项目骨架
2. 指导我创建前端项目骨架
3. 规划登录与鉴权链路

第三阶段：
1. 分批生成后端 entity
2. 分批生成 repository
3. 分批生成 service
4. 分批生成 controller
5. 最后补 config、JWT、异常处理

第四阶段：
1. 分批生成前端 request/api
2. 分批生成 store/router
3. 分批生成页面骨架
4. 分批生成地图组件

第五阶段：
1. 帮我制定联调清单
2. 帮我制定测试清单
3. 帮我指出常见坑

要求：
- 全程以中小型业务系统最佳实践为标准
- 结构清晰
- 职责单一
- 统一返回格式
- 后端鉴权必须真实生效
- 用教学方式说明每一步为什么这样做
