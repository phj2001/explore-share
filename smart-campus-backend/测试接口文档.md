# 智慧校园后端 - API测试说明

## 一、启动后端项目

### 方式一：使用 IntelliJ IDEA（推荐）

1. 打开 IntelliJ IDEA
2. 打开项目：`File` → `Open` → 选择 `smart-campus-backend` 目录
3. 等待Maven依赖下载完成
4. 找到 `src/main/java/com/smartcampus/SmartCampusBackendApplication.java`
5. 右键点击 → `Run 'SmartCampusBackendApplication'`
6. 看到控制台输出 `Started SmartCampusBackendApplication` 表示启动成功

### 方式二：使用命令行

```bash
# 在项目目录下执行
./mvnw spring-boot:run
```

### 方式三：使用 Maven 命令

```bash
# 在项目目录下执行
mvn spring-boot:run
```

---

## 二、确认启动成功

启动成功后，控制台会显示：
```
Started SmartCampusBackendApplication in X.XXX seconds
```

访问 `http://localhost:8080` 应该会有响应

## 四、手动测试接口

### 1. 用户认证接口

#### 注册用户
```bash
curl -X POST http://localhost:8080/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"test001","password":"123456"}'
```

#### 用户登录
```bash
curl -X POST "http://localhost:8080/api/auth/login?username=test001&password=123456"
```

#### 检查用户名是否存在
```bash
curl http://localhost:8080/api/auth/check?username=test001
```

---

### 2. POI接口（公开-查询）

#### 获取所有POI
```bash
curl http://localhost:8080/api/pois
```

#### 按名称搜索
```bash
curl http://localhost:8080/api/pois/search?name=图书馆
```

#### 按分类查询
```bash
curl http://localhost:8080/api/pois/category/学习
```

#### 获取所有分类
```bash
curl http://localhost:8080/api/pois/categories
```

---

### 3. POI接口（需要登录-增删改）

#### 1. 先登录获取 Token
```bash
curl -X POST "http://localhost:8080/api/auth/login?username=test001&password=123456"
```

响应示例：
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiJ9...",
    "userId": 1,
    "username": "test001",
    "role": 1
  }
}
```

#### 2. 使用 Token 创建 POI
```bash
curl -X POST http://localhost:8080/api/pois \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..." \
  -d '{"name":"测试图书馆","category":"学习","description":"校园图书馆","latitude":39.9042,"longitude":116.4074}'
```

#### 3. 更新 POI
```bash
curl -X PUT http://localhost:8080/api/pois/1 \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..." \
  -d '{"name":"图书馆（已更新）","category":"学习","description":"更新后的描述","latitude":39.9042,"longitude":116.4074}'
```

#### 4. 删除 POI
```bash
curl -X DELETE http://localhost:8080/api/pois/1 \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..."
```

---

### 4. 路径规划接口

#### 规划路径
```bash
curl -X POST "http://localhost:8080/api/routes/plan?startLat=39.9&startLng=116.4&endLat=39.92&endLng=116.41"
```

#### 查找附近POI
```bash
curl "http://localhost:8080/api/routes/nearby?lat=39.9&lng=116.4&radius=1"
```

## 五、使用 Postman 测试（推荐）

### 导入接口集合

创建一个新的 Postman Collection，添加以下接口：

| 接口 | 方法 | URL | 需要Token |
|------|------|-----|----------|
| 用户注册 | POST | `/api/auth/register` | ❌ |
| 用户登录 | POST | `/api/auth/login` | ❌ |
| 检查用户名 | GET | `/api/auth/check` | ❌ |
| 获取所有POI | GET | `/api/pois` | ❌ |
| 搜索POI | GET | `/api/pois/search?name=xxx` | ❌ |
| 按分类查询 | GET | `/api/pois/category/{category}` | ❌ |
| 创建POI | POST | `/api/pois` | ✅ |
| 更新POI | PUT | `/api/pois/{id}` | ✅ |
| 删除POI | DELETE | `/api/pois/{id}` | ✅ |

### 在 Postman 中设置 Token

1. 先调用登录接口获取 token
2. 在需要Token的请求中添加 Header：
   - Key: `Authorization`
   - Value: `Bearer <你的token>`

## 六、常见问题

### 1. 端口被占用
修改 `application-dev.properties` 中的 `server.port`

### 2. 数据库连接失败
确认 PostgreSQL 已启动，用户名密码正确

### 3. 401 Unauthorized
检查 Token 是否正确，格式为 `Bearer <token>`

### 4. 密码安全问题
注册后密码会自动加密，数据库中存储的是加密后的密码
